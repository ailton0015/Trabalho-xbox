# 🎮 Dashboard de Vendas | Xbox Game Pass

Este repositório contém a entrega do projeto prático de visualização e análise de dados de vendas de assinaturas do ecossistema gamer (**Xbox Game Pass**, **EA Play** e **Minecraft**), desenvolvido em **Microsoft Excel**.

---

## 📊 Estrutura da Planilha

O ficheiro `Trabalho xbox.xlsx` está organizado nas seguintes abas:

- **`Dashboard`**: Painel visual dinâmico com cabeçalho explicativo, seletor de plano (ex.: *Annual*, *Monthly*, *Quarterly*), cartões de indicadores (KPIs) para **EA Play**, **Minecraft**, **Game Pass: Sim** e **Game Pass: Não**, além da área de comparação visual por plano.
- **`Dados`**: Base de consolidação dos registos transcritos por tipo de plano (*Annual*, *Monthly*, *Quarterly*), contendo os faturamentos em Reais (R$) para cada produto e a identificação das fontes de referência de dados.

## 🚀 Como Utilizar

1. Faça o download do ficheiro **`Trabalho xbox.xlsx`** localizado neste repositório.
2. Abra o ficheiro no **Microsoft Excel**.
3. Navegue pela aba **`Dashboard`** para consultar os indicadores dinâmicos e utilize a aba **`Dados`** para verificar a base de suporte.
